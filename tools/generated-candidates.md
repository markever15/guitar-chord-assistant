# 자동 탐색으로 찾은 후보 보이싱 (미채택)

사용자가 직접 보낸 코드가 아니라, 구성음을 다 담으면서 잡을 수 있는 폼을
지판 전수 탐색으로 찾아낸 것들이다. `generatedVoicings.js`에는 넣지 않는다.
직접 잡아보고 쓸 만하다고 판단되면 그때 옮기면 된다.

탐색 조건: 구성음 전부 울림 · 루트가 최저음 · 손 벌림 4프렛 이내 ·
`computeFingers`가 운지 배정에 성공 · 기존 데이터와 프렛 중복 없음.

찾은 계기: 11 계열(6음 코드)에서 사용자가 보낸 변형들이 11음을 떨어뜨려
전부 9 코드가 되어버렸는데, 한 자리 수정으로는 전부 기존 폼으로 수렴해
새로 넣을 게 없었다. 그래서 "그 구간에 실제로 빠진 폼이 있나"를 따로 뒤진 결과다.

## G11 (2026-08-01 탐색)

| frets | fingers |
|---|---|
| `15,15,12,14,0,13` | `4,4,1,3,0,2` |
| `15,0,12,16,13,13` | `3,0,1,4,2,2` |
| `15,12,0,16,13,13` | `3,1,0,4,2,2` |
| `15,12,12,16,13,13` | `3,1,1,4,2,2` |

## Gm(maj11)

| frets | fingers |
|---|---|
| `3,3,7,7,7,6` | `1,1,4,4,4,3` (바레) |
| `3,0,0,5,7,6` | `1,0,0,2,4,3` |
| `3,3,0,3,7,5` | `1,1,0,2,4,3` |
| `15,15,0,14,11,14` | `4,4,0,2,1,3` |

마지막 것은 11음 C를 5번줄 15프렛에서 낸다. C는 2번줄 13프렛 말고도
5번줄 15프렛에서 낼 수 있어서, 12프렛대에서 C를 배치할 자리가 두 군데다.
