# 자동 탐색으로 찾은 후보 보이싱 (미채택)

사용자가 직접 보낸 코드가 아니라, 구성음을 다 담으면서 잡을 수 있는 폼을
지판 전수 탐색으로 찾아낸 것들이다. `generatedVoicings.js`에는 넣지 않는다.
직접 잡아보고 쓸 만하다고 판단되면 그때 옮기면 된다.

탐색 조건: 구성음 전부 울림 · 루트가 최저음 · 손 벌림 4프렛 이내 ·
`computeFingers`가 운지 배정에 성공 · 기존 데이터와 프렛 중복 없음.

찾은 계기: 11 계열(6음 코드)에서 사용자가 보낸 변형들이 11음을 떨어뜨려
전부 9 코드가 되어버렸는데, 한 자리 수정으로는 전부 기존 폼으로 수렴해
새로 넣을 게 없었다. 그래서 "그 구간에 실제로 빠진 폼이 있나"를 따로 뒤진 결과다.
